## Overview

![docs/data/seo_plugin_example.png](doc/data/seo_plugin_example.png)

This Plugin provides an almost plug and play solution for your SEO needs:

- Metadata and OpenGraph for channels, products, taxons and any shop URL, with a Google / Twitter / Facebook preview in the admin
- **Marketing > SEO** admin page listing all SEO contents
- Per-locale indexability and noindex rules on routes (e.g. paginated or sorted taxon pages)
- Canonical and hreflang links
- Breadcrumb and Product RichSnippets (JSON-LD), with GTIN / MPN / SKU per product or per variant
- Google Analytics and Google Tag Manager through your channel configuration
- API Platform endpoints for SEO contents

| Plugin | Sylius | PHP |
|---|---|---|
| 4.x | 2.0 to 2.3 | 8.2+ |
| 3.x | 1.11 to 1.14 | 8.0+ |
